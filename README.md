# Landing Page Layanan Finansial

Project Vite React untuk halaman informasi layanan bantuan finansial.

Catatan keamanan: halaman ini bukan situs resmi institusi keuangan mana pun. Jangan gunakan untuk meminta OTP, PIN, password, data kartu, dokumen identitas, atau data sensitif pengguna.

## Jalankan lokal

```bash
npm install
npm run dev
```
